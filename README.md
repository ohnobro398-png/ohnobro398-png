## Executive Introduction

I build privacy-first software and secure my own systems. My work centers on **defensive security**: understanding how applications break so I can harden them before anyone else finds the weakness.

- **What I engineer:** client-side web tools, Android apps, and agent-skill systems — all designed to collect as little data as possible.
- **What problems I solve:** tools that solve real daily problems, and security gaps in my own code and sites, found by auditing first and shipping second.
- **Security philosophy:** defense first, authorized scope only, evidence over claims. I audit my own systems and practice only in authorized labs — never on sites I do not own.
- **Current focus:** a 12-week defensive cybersecurity mentorship (Linux, networking, web application security) alongside building and shipping tools.
- **Also:** founder of Shokhbox, an f-commerce brand.
